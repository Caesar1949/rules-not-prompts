# 前端规则（SwiftUI）

> **替换占位符**：`⟨App/**⟩` 改成你实际的 UI 源码目录，如 `Sources/App/**`。
> 注意 `paths` 每一项必须是**真实存在的文件 glob**，否则规则永不激活。

## 导航

- 全局唯一路由单例，根导航栈只在 App 入口创建
- 导航栈是框架私有类型，**不可遍历**（`for-in` / `makeIterator()` / `Array(_)` 均不可用）
- 栈信息一律读公开接口：`canGoBack` / `pathCount` / `navigate` / `goBack`
- 目标视图的 `body` 内禁止再包一层导航栈（sheet 呈现的视图除外，那是独立宿主上下文）

## 状态管理

- 优先 `@Observable`（新项目不要用 `@ObservableObject` / `@Published`）
- 所有 UI 相关类型标注 `@MainActor`
- **ViewModel `init` 必须纯赋值**：禁止在 `init` 里启动 `Task` / `Timer` / 订阅通知
- 副作用写成显式方法，由视图的 `.task` / `.onAppear` 触发
- 跨页面共享的 ViewModel 用 `static let shared`

## 副作用与重建

- 禁止用 `.id(⟨某个值⟩)` 强制重建整棵视图树做主题切换——会销毁全部 `@State` 与导航状态
- 主题切换走可观察对象 + 通知重设外观

## 路由跳转

- 禁止占位 ID 跳转（`"0"` / `"default"` / 空字符串）
- 数据未就绪时禁用入口或提示，不要跳到下游降级成伪造数据的页面

## 资源

- 图片资源需手动加入工程文件结构（工具链无法自动识别新增资源）
- 新增资源后立即构建验证一次

## 设计令牌

- 所有颜色 / 字体 / 间距 / 圆角 / 阴影必须走设计令牌
- 禁止在视图中硬编码样式值

## 服务层

- 真实服务与 Mock 服务并存，通过工厂切换
- 调试数据用 `Mock*Service`，**不要改真实服务**（R006）

## 平台归属（多端项目）

改动前先识别 API 属于哪一端，避免「修 1 端 3 端都变」。

| 类别 | 处理 |
|---|---|
| 单端独有 | `#if os(⟨平台⟩)` 包裹，公用层禁止 import |
| 两端差异 | `extension` + `#if` 隔离，不污染主类 |
| 公用 | 加 `// PLATFORM: shared — verify ⟨平台列表⟩` 注释 |

**改后验证**：

- 多 target 双编译（每个 target 都要绿）
- 在主力平台上跑一次主流程，确认无视觉 / 行为回归
